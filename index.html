Clip Studio

Clip Studio is a personal desktop application that helps its owner edit short vertical clips from full-length podcast episodes and publish them to the owner's own social media accounts. It is not a public service: it runs only on the owner's computer, and has no user sign-ups and no other users.

What it does

  • Takes a full podcast episode that the owner is authorized to clip (as a member of the show's official clipping program), and finds strong 30–90 second moments.
  • Edits each moment into a vertical video with captions and the show's watermark, which the owner reviews and approves by hand.
  • When the owner clicks Upload on an approved clip, it publishes that video to the owner's own account through each platform's official API, with the title and description the owner approved.

How it uses the YouTube API

  • Scopes: youtube.upload (to upload the owner's approved clips to the owner's own channel) and youtube.readonly (to show which channel is connected).
  • Every upload is started manually by the owner. Nothing is uploaded automatically or on a schedule.
  • It does not read, collect, or change any other YouTube data, and it never accesses anyone else's account.
  • Sign-in tokens are stored only on the owner's computer. There is no Clip Studio server, and no data is sent anywhere except directly to YouTube.
